# QOC-001: Хто відповідає за розрахунок вартості відправки

- **Question:** Хто повинен обчислювати транспортний збір, страховку та
  загальну вартість відправки?
- **Options:**
  - *Option A:* Залишити розрахунок у методі консольного процесора.
  - *Option B:* Створити окремий `ShipmentCostService`, що читає поля сутностей.
  - *Option C:* Перенести обчислення в `Shipment` та `Cargo`, а тип
    транспорту виразити через політику тарифу.
- **Criteria:**
  - *Information Expert:* `Cargo` знає вагу та цінність, `Shipment` знає
    тип доставки.
  - *Low Coupling:* консоль не повинна залежати від алгоритму розрахунку.
  - *Protected Variations:* нові типи транспорту не повинні змінювати `Shipment`.
- **Conclusion:** Обрано Option C. Option B лишає Anemic Domain Model
  (сервіс оперує чужими полями), Option A порушує все.
