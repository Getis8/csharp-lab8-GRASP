# ADR-002: Створення Shipment через статичний фабричний метод

## Статус
Прийнято (Accepted)

## Контекст
У legacy `Shipment` створюється порожнім і заповнюється покроково ззовні,
тому можливі невалідні стани (без відправника, з нульовою вагою).

## Рішення
Згідно з GRASP **Creator** об'єкт створюється у валідному стані через
статичний метод `Shipment.Create(...)`. Конструктор закритий, всі інваріанти
перевіряються guard clauses до створення.

## Наслідки
* **Позитивні:** неможливо отримати невалідний `Shipment`; fail-fast.
* **Негативні:** трохи більше коду, ніж у `new Shipment { ... }`.
